# הנחיות פיתוח

## שפה ו-RTL
- כל טקסט שמוצג למשתמש חייב להיות בעברית.
- יש לשמור על `dir="rtl"` ברמת ה-HTML.
- ב-Tailwind משתמשים רק ב-logical utilities:
  - `ms-*` ו-`me-*` במקום `ml-*` ו-`mr-*`
  - `ps-*` ו-`pe-*` במקום `pl-*` ו-`pr-*`

## Design System
- משתמשים ב-tokenים שהוגדרו ב-`app/globals.css`.
- רכיבים חוזרים מגיעים רק מ-`components/ui`.
- אין ליצור וריאציות עיצוב חדשות בכל מסך; מרחיבים רכיבים קיימים.
- שיפורי נראות מצטברים ורשימת ביקורת: [`UI_NOTES.md`](UI_NOTES.md).

## קוד וארכיטקטורה
- שמות משתנים ופונקציות באנגלית ובמשמעות ברורה.
- קבצים גדולים מתפצלים לרכיבים/מודולים קטנים.
- לוגיקה מורכבת מקבלת הערה קצרה שמסבירה למה.
